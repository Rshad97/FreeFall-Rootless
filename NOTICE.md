# Notice

FreeFall Rootless is a modern rootless port derived from the historical FreeFall project and the alexPNG fork. The project source code remains distributed under GPL-3.0.

## Default sound

Version 3.0.1 uses the classic **Wilhelm Scream** as its default fall sound. The documented build helpers fetch the WAV from the USC/Sunset Editorial sound-effects collection hosted by Internet Archive. The collection and the corresponding Wikimedia Commons Wilhelm Scream file identify the sound as CC0 1.0 / public-domain dedicated.

See `AUDIO_LICENSE.md` for source and licensing details.
